# 🧭 Path Finder Visualization

An interactive **Path Finding Visualizer** built using **HTML, CSS, and JavaScript** that demonstrates how pathfinding algorithms like **Dijkstra’s**, **A\***, **BFS**, and **DFS** work in real-time.  
This project provides a visual and intuitive understanding of how different algorithms find the shortest path between two points in a grid.

---

## 🚀 Live Demo

🔗 **[View on Vercel](https://path-finder-omega-virid.vercel.app/)**  

---

## 🧩 Features

✅ Visualize popular pathfinding algorithms in action  
✅ Select start and end nodes interactively  
✅ Draw walls or obstacles on the grid  
✅ Compare algorithm performance visually  
✅ Dynamic speed control for animation  
✅ Reset and clear grid functionality  
✅ Responsive and minimal design  

---

## 🧠 Algorithms Implemented

- 🟩 **Dijkstra’s Algorithm** – The classic shortest path algorithm  
- 🟨 **A\* Search** – Uses heuristics for efficient pathfinding  
- 🟦 **Breadth-First Search (BFS)** – Explores nodes level by level  
- 🟥 **Depth-First Search (DFS)** – Explores as far as possible before backtracking

🧑‍💻 How It Works

1.Select the algorithm you want to visualize

2.Click on the grid to set:
🟩 Start Node
🟥 End Node
⬛ Walls or Obstacles
3.Click “Visualize” to run the algorithm
4.Watch how the algorithm explores and finds the path!
